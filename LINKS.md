## Ebook Management Software

[Calibre](https://calibre-ebook.com/) is the open-source, Swiss Army knife of e-book management. It goes far beyond simply reading PDFs and EPUBs, offering several standout features:

**Universal Format Conversion** - Convert almost any input format (EPUB, MOBI, AZW3, PDF, DOCX, TXT) into any output format with fine-grained control

**Built-in Content Server (Personal Cloud Library)** - Calibre includes its own web server. Turn it on, and you can access your entire library remotely from a web browser on your smartphone, tablet, or secondary computer.

**Automated Metadata & Cover Scraping** - Input an incomplete filename, and Calibre can query Google Books, Amazon, Goodreads, and Open Library to download the exact book title, author, publisher, publication date, series order, and high-resolution cover art.   

**Direct E-Book Editor** - For EPUB and AZW3 files, Calibre has a full built-in code and visual editor. You can tweak internal CSS stylesheets, remove publisher-forced fonts, fix broken chapter breaks, embedded images, or bad hyphenation without needing separate tools like Sigil.

**Massive Plugin Ecosystem** - Calibre’s open architecture supports a massive library of community-made plugins. Key plugins allow you to:   
  - Automatically download entire fanfiction stories from platforms like AO3 using FanFicFare.
  - Merge multiple EPUBs into an omnibus or split large files into individual volumes (EpubSplit / EpubMerge).
  - Send native Kobo metadata or custom tags to e-readers via dedicated device drivers.

**Automated News and RSS Scraping ("Fetch News")** - Schedule Calibre to fetch full articles from news outlets, blogs, or RSS feeds (like The New Yorker, BBC, or The Economist). It converts the articles into an e-book with a formatted Table of Contents and pushes it directly to your e-reader overnight.   

**Smart Device Sync & On-the-Fly Transcoding** - Plug in a Kindle, Kobo, or Nook via USB, and Calibre automatically detects the hardware, scans the device's contents, updates series tags, and converts any non-supported book formats to the reader's preferred file type before transferring.   

**Custom Metadata Columns & Virtual Libraries** - Track reading progress, custom tags (e.g., "DNF", "To-Be-Read", custom word counts, purchase origin), or setup virtual libraries that filter your main library by genre, reading status, or language at a click.
